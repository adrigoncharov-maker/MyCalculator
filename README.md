# Консольный калькулятор на C#

Простой и надёжный консольный калькулятор, написанный на C# (.NET). Проект создан для практики базовых конструкций языка, работы с математической библиотекой `Math` и обработки пользовательского ввода.

## Возможности
- **Базовые операции:** сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
- **Дополнительные вычисления:** возведение в степень (`^`) и извлечение квадратного корня (`sqrt`).
- **Защита от ошибок:**
  - Проверка корректности ввода чисел с помощью `double.TryParse` (программа не падает при вводе букв или символов).
  - Защита от деления на ноль.
  - Проверка на извлечение квадратного корня из отрицательного числа.
  - Автоматическая очистка лишних пробелов при вводе знака операции.

## Пример использования
```text
Введите первое число:
16
Введите знак:
sqrt
Результат: 4
```
